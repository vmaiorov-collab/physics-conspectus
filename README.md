# Physics notes (mechanics)

Site: **https://vmaiorov-collab.github.io/physics-conspectus/**

Ten topics based on handwritten class notes: vectors, kinematics, uniformly accelerated motion, mass and density,
Newton's laws, pulleys, Hooke's law, friction, statics, momentum and centre of mass.

Each set of notes is a single HTML file (KaTeX formulas and SVG drawings are embedded) that opens offline.
The design follows [conspectus](https://github.com/vmaiorov-collab/conspectus).

## Build

```bash
python3 tools/build.py
```

Texts are in `content/`; drawings (SVG generated by code) are in `tools/figures.py` and `tools/figures2.py`.
