1. String tension

  • A string can only pull, never push. If one end is pulled with force $F$ and the other is fixed, then $T = F$.
  • A heavy string of mass $M$ and length $L$ with a load $m$ below: at height $x$ above the load the string holds the load and its own lower part, $$T(x) = mg + \frac{Mg}{L}x.$$ If the mass of the string can be neglected, $T$ is the same along its whole length.
  • If a pulley is frictionless (and massless), the tension is the same on both sides of it.

2. Two kinds of pulleys

A fixed pulley only changes the direction of a force. On the axle of a movable pulley two tensions act: $2T = F$.

Infinite cascade

There are infinitely many movable pulleys with loads $M$. Adding one more stage changes nothing, so the tension $A$ in the string of a very distant pulley satisfies $A = \dfrac{A + Mg}{2}$, hence $A = Mg$.

3. When equilibrium is impossible

3a. A load $2m$ at the end of the string, loads $m$ and $M$ on the movable pulleys. Then $T = 2mg$, but the pulley with load $m$ needs $mg = 2T = 4mg$. For $m \ne 0$ this is impossible.

4. Lab: weighing a load with a weak newtonmeter

Problem. The load is heavier than 250 g, but the newtonmeter is rated for only 2.5 N: it cannot be measured directly, the meter would break.

Idea. Hang the load on a string and pull the knot $K$ aside with the newtonmeter, keeping it horizontal.

§lab_weigh§ §lab_triangle§

The knot is at rest, so $\sum\vec F = 0$: the triangle of forces $\vec W, \vec F, \vec T$ is similar to the triangle $y, x, l$. By Pythagoras $y = \sqrt{l^2 - x^2}$, therefore

$$\frac{W}{y} = \frac{F}{x} \quad\Rightarrow\quad W = F\,\frac{y}{x} = F\,\frac{\sqrt{l^2-x^2}}{x}.$$

Instruments: a newtonmeter and a ruler; the weight is found by calculation. The newtonmeter is calibrated in the horizontal position beforehand.

Measurements (l = 25 cm)

The average is about $4$ N, so the mass is about $400$ g.

Analysis

  • Why three measurements. With two you cannot tell which one is an outlier; three different values of $F$ let you check.
  • Small x is inconvenient: we divide by $x$, so the same ruler error gives a larger relative error.
  • Too large x is inconvenient too: $y$ starts to change noticeably, since $\dfrac{d}{dx}x^2 = 2x$ grows with $x$.
  • How to measure x and y: hold one ruler parallel to the floor and use it as a guide for finding the distance with a second one; measure the length along the string with a ruler laid against the string.
  • Sources of error: the newtonmeter was not calibrated in the horizontal position (zero must be set exactly like that) and may not have been held parallel to the floor.
  • Checking without electronic scales: weigh a bottle after drinking a known amount of water from it. Discrepancy: $\dfrac{2\,|m_\text{scales} - m_\text{lab}|}{m_\text{scales}+m_\text{lab}}$. A reference of unverified accuracy is not reliable in itself.
  • Hazard: the string breaks and the load falls. Precaution: use a strong string.

A water bottle assumed to be “400 g” without being checked on scales is an unreliable reference.

How F depends on x

From the formula $F = W\cdot\dfrac{x}{y} = W\dfrac{x}{\sqrt{k-x^2}}$, where $k = l^2$. The derivative:

$$\frac{d}{dx}\frac{x}{\sqrt{k-x^2}} = \frac{\sqrt{k-x^2} + \dfrac{x^2}{\sqrt{k-x^2}}}{k-x^2} = \frac{k}{(k-x^2)^{3/2}} \gt 0.$$

The derivative is always positive: the larger the deflection $x$, the larger the force $F$ needed.

Important addition

The graph of $F$ against the ratio $x/y$ is a straight line through the origin with slope $W$. Plotting it through several points gives the weight more accurately than a single measurement.
