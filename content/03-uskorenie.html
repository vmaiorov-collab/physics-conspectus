1. Ускорение

$$\vec a = \frac{\Delta\vec v}{\Delta t}, \qquad \Delta t \to 0.$$

Ускорение отлично от нуля в двух случаях: меняется величина скорости или меняется её направление.

2. Вывод x(t) при постоянном ускорении

Движение по прямой: в момент $t=0$ тело находится в точке $x_0$, имеет скорость $v_0$ и ускорение $a$.

§acc_axis§

При $a_x = \text{const}$ имеем $a_x = \dfrac{v_x - v_{0x}}{t}$, откуда

$$v_x(t) = v_{0x} + a_x t.$$

Перемещение — площадь под графиком скорости, то есть площадь трапеции:

§acc_trap§ $$\Delta x = \int_0^t v_x\,dt = \frac{v_{0x} + v_x(t)}{2}\,t, \qquad \langle v_x\rangle = \frac{v_{0x}+v_x(t)}{2}.$$

Подставляем $v_x(t)$:

Важно$$x(t) = x_0 + v_{0x}t + \frac{a_x t^2}{2}$$

График $x(t)$ — парабола. При $v_{0x}\gt0,\ a_x\gt0$ координата сразу растёт; при $v_{0x}\lt0,\ a_x\gt0$ тело сначала идёт назад, достигает минимума и поворачивает.

§acc_cases§

3. Формула без времени

Из $v_x = v_{0x} + a_x t$ выражаем $t$ и подставляем в формулу площади:

$$\Delta x = \frac{v_x^2 - v_{0x}^2}{2a_x}.$$

Подробно: $\Delta x = \dfrac{v_{0x}+v_x}{2}\,t$ и $t = \dfrac{v_x - v_{0x}}{a_x}$, а произведение $(v_x+v_{0x})(v_x-v_{0x})$ — разность квадратов. Если вместо начальной скорости известна конечная, то $\Delta x = v_x t - \dfrac{a_x t^2}{2}$.

Значит, квадрат скорости линейно зависит от перемещения:

§acc_v2§

Скорость в середине пути

Тело разгоняется от $v_0 = 1$ м/с до $v = 7$ м/с. Какова скорость $v_1$ на середине отрезка?

Весь путь: $\Delta x = \dfrac{49 - 1}{2a} = \dfrac{24}{a}$. Половина: $\dfrac{\Delta x}{2} = \dfrac{v_1^2 - 1}{2a}$. Делим первое на второе:

$$2 = \frac{48}{v_1^2 - 1} \;\Rightarrow\; v_1 = 5\ \text{м/с}.$$

Торможение: скорость на половине тормозного пути

$S = \dfrac{0 - v_0^2}{-2a}$ и $\dfrac S2 = \dfrac{v_1^2 - v_0^2}{-2a}$. Отношение даёт $2v_1^2 = v_0^2$, то есть $v_0 = v_1\sqrt2$.

Тормозной путь 100 м

Тормозной путь $S = 100$ м, в его середине скорость $10$ м/с, в конце — ноль. Найти начальную скорость, ускорение и время торможения.

§acc_brake§

По предыдущей задаче $v_0 = 10\sqrt2 \approx 14{,}1$ м/с. Далее

$$a = \frac{v_0^2}{2S} = \frac{200}{200} = 1\ \text{м/с}^2, \qquad t = \frac{2S}{v_0} = \frac{200}{10\sqrt2} \approx 14{,}1\ \text{с}.$$

(Первая попытка в тетради с $v_0 = 20$ м/с зачёркнута.)

4. Торможение с разворотом

Начальная скорость $v_0$ вдоль оси, ускорение $a$ — против. Найти $d_x(t)$ и путь $S(t)$.

$$d_x(t) = v_0 t - \frac{at^2}{2}.$$

Тело останавливается и поворачивает в вершине параболы: $t_0 = v_0/a$. До этого момента путь совпадает с перемещением, после — продолжает расти:

$$S(t) = \begin{cases} v_0 t - \dfrac{at^2}{2}, & t \le t_0,\\[2mm] \Big(v_0 t_0 - \dfrac{at_0^2}{2}\Big) + \dfrac{a(t-t_0)^2}{2}, & t \gt t_0. \end{cases}$$ §acc_back§
Исправление

В тетради в первой ветви $S(t)$ стоит «+» перед $at^2/2$. Так как тело тормозит, там должен быть «−».

5. Пути за равные промежутки времени

Старт из покоя, промежутки по $\tau$. Площади под прямой $v = at$ за первый, второй, третий промежутки равны $\frac{a\tau^2}{2}$, $3\cdot\frac{a\tau^2}{2}$, $5\cdot\frac{a\tau^2}{2}$:

$$S_1 : S_2 : S_3 : \ldots = 1 : 3 : 5 : \ldots$$ §acc_odd§

То же самое для шарика на наклонном жёлобе: отрезки, пройденные за равные времена, относятся как последовательные нечётные числа.

§acc_slope§

6. Разгон в два этапа

Сначала ускорение $a_1$ в течение $t_1$, затем $a_2$ в течение $t_2$. После первого этапа скорость $v_1 = a_1 t_1$, она и есть начальная для второго:

§acc_two§ $$S = \frac{a_1t_1^2}{2} + a_1t_1t_2 + \frac{a_2t_2^2}{2}.$$

7. Лабораторная: скатывание по наклонной плоскости

Тело стартует из покоя и проходит длину $L = 125$ см за время $t$. Тогда $L = \dfrac{at^2}{2}$, то есть $a = \dfrac{2L}{t^2}$. Угол задаётся высотой подъёма: $\sin\varphi = h/L$.

8. Записи на полях

Рядом с задачами есть вычисления без записанного условия:

$$\Delta s = \Delta v\cdot t + \Delta t\cdot v, \qquad v = \frac{\Delta v}{\Delta t}\,t + v_0.$$

Скорость меняется на $15$ м/с за $6$ минут: $a = \dfrac{15}{360} = \dfrac1{24}$ м/с². Тогда через $60$ с $v = \dfrac1{24}\cdot 60 + 2{,}5 = 5$ м/с, и отдельно записано $5 - 15 = -10$ м/с.
